# RM-018 — Golden error messages for huginn.
#
# Error strings are API: callers match on them, so every typed
# error's message shape is pinned here. CASE lines are exact
# messages produced by deterministic triggers in
# test_error_messages.py (a store path under the test's tmp dir
# is normalised to <tmp_path>; Qdrant failures are produced
# against a fake client whose methods raise RuntimeError("boom")
# — no live server is involved, and live Qdrant stays NOT
# PROVEN). TEMPLATE lines are the message template of every
# `raise Huginn*Error(...)` site in src/, extracted by AST with
# f-string interpolations shown as {} — the test re-extracts
# them, so adding or editing a raise site fails until this
# file is updated deliberately in the same commit as the
# change.
#
# CASE lines (70): every raise site except the two that
# cannot be triggered deterministically — the "document
# insert reported success but returned no row id" guards
# (unreachable by construction; RM-008), pinned below as
# TEMPLATE lines (the guard appears twice, once per insert
# path). (RM-054: "could not be prepared" gained a
# deterministic trigger — a store trigger that aborts the
# prepare-time meta insert — and is a CASE line now.)
