# RM-018 — Golden error messages for muninn.
#
# Error strings are API: callers match on them, so every typed
# error's message shape is pinned here. CASE lines are exact
# messages produced by deterministic triggers in
# test_error_messages.py (a store path under the test's tmp dir
# is normalised to <tmp_path>). TEMPLATE lines are the message
# template of every `raise Muninn*Error(...)` site in src/,
# extracted by AST with f-string interpolations shown as {} —
# the test re-extracts them, so adding or editing a raise site
# fails until this file is updated deliberately in the same
# commit as the change.
#
# CASE lines (53): every raise site except the two that cannot
# be triggered deterministically — "could not be prepared"
# (needs a store whose schema script fails mid-open) and "node
# insert reported success but returned no row id" (unreachable
# by construction; the RM-008 guard). Both are pinned below as
# TEMPLATE lines.
